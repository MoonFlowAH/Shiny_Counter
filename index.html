Only Text (GDI+/FreeType 2) sources appear for text fields, and only Browser sources for Sprite — add one of each in OBS first if a list comes up empty. The sprite is pushed as a self-contained transparent page (not a bare image link), so the Browser Source should render with no black or white border behind it automatically — no Custom CSS needed on your end for that. The milestone alert briefly swaps the sprite source for a celebration graphic, then returns to the normal sprite — it needs a sprite source picked above. Compact mode is handy for a smaller stream overlay footprint — it pushes one "Name · Count · Timer" line into a single text source instead of managing three separate ones.
